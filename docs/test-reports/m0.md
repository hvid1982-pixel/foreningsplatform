## Gate for Milestone 0

> Ejer eller udvikler kan køre appen lokalt og logge ind som hver rolle.

Opfyldt lokalt og på staging: E2E-testene logger ind som platformadmin, foreningsadmin og virksomhedsadmin og ser hvert sit overblik. Ejeren har 2026-11-04 logget ind og klikket rundt som admin og forening på Vercel-preview'et (Dublin, Supabase eu-west-1).

## Kendte begrænsninger

- Docker Compose-filen er skrevet, men ikke afprøvet i udviklingsmiljøet (Docker var ikke tilgængeligt der); testene er kørt mod en lokal PostgreSQL 16 med samme opsætning. CI bruger samme Postgres-image som compose-filen.
- Fuld e-mailbekræftelse i browseren er testet via integrationstest (token fra mailen), ikke via E2E mod Mailpit.
- I udviklingstilstand logger Next.js en advarsel om `instant`-validering, når en ikke-admin omdirigeres væk fra admin. Det er forventet og påvirker ikke produktion.
- Admin kan se forretningsregler, men endnu ikke ændre dem i UI'et (service og tests findes; UI kommer i M1).
